# Asset Ease – Asset Management System

**Asset Ease** is a comprehensive full-stack web application designed to streamline and manage organizational assets efficiently. The system allows admins to add, assign, return, and schedule maintenance for assets, as well as manage users.

---

## 🌟 Features

- Add new assets and users
- Assign and return assets
- Schedule asset maintenance
- View all users and all assets
- User authentication & admin roles
- Clean, responsive UI with global CSS (Tailwind)

---

## 🛠️ Tech Stack

**Frontend:**
- ReactJS (with Vite)
- Tailwind CSS
- React Router DOM

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose)
- Thunder Client (for API testing)

**Tools:**
- GitHub (collaboration)
- GitHub Desktop

**How to run the project:**
- For Frontend:
cd Frontend 
npm run dev
- For Backend:
cd Backend
nodemon app.js
